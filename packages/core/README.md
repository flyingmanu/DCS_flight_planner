Logique métier partagée entre les futures applications web et desktop : modèles de
données (théâtres, aérodromes, waypoints), calculs de navigation, conversions de
coordonnées.

En attente des premières données réelles issues de `tools/dcs-export` avant de figer
le schéma de données — voir la racine du repo pour l'état d'avancement.
